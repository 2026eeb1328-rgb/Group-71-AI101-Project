# Member 2 Deliverables

Copy the files/folders into the matching paths in your main repository.

- `notebooks/02_preprocessing.ipynb`
- `src/preprocessing.py`
- `src/feature_selection.py`
- `reports/results/member2_cv_results_observed.csv`
- `reports/results/feature_selection_config_observed.json`
- `MEMBER2_HANDOVER.md`

Place the original dataset at `data/raw/Data.csv` before running the notebook.
The notebook saves split membership and the selected configuration under the repository's `data/processed/` and `reports/results/` folders.

Install dependencies with:
`pip install pandas numpy scikit-learn matplotlib jupyter`
